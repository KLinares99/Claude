Full-width dark navy stat strip — trust signals (years of experience, rating, availability, languages).

```jsx
<StatBand stats={[
  { value: '20+', label: 'Years of experience' },
  { value: '5.0', label: 'Client rating ★★★★★' },
  { value: '24/7', label: 'Availability, year-round' },
  { value: '2', label: 'Languages — English y Español' },
]} />
```

Always sits on `--navy-900`, full section width — never embedded inside a card.
