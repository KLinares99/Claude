Primary CTA button in four visual variants, used for every clickable action across the marketing site.

```jsx
<Button variant="primary" href="#">Schedule a Consultation</Button>
<Button variant="dark" href="#">Make a Payment</Button>
<Button variant="outline" href="#">Learn More</Button>
<Button variant="light" size="sm" href="#">Request a Quote</Button>
```

Variants: `primary` (cyan, dark-navy text — the main booking/quote CTA), `dark` (navy-900 fill — transactional actions like payments), `outline` (navy border, inverts to filled navy on hover), `light` (white fill, used on dark backgrounds like the hero). `size="sm"` tightens padding for header/nav placements.
